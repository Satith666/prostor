WinPulse для Windows 10/11 (x64).

**Установка:** скачайте `WinPulse-Setup-*.exe` и запустите — права администратора не нужны, программа ставится для текущего пользователя и обновляется сама. Переносная версия — `WinPulse-*-portable.zip`.

Сборка пока без цифровой подписи: при первом запуске Windows SmartScreen может показать «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае». Контрольные суммы — в `SHA256SUMS.txt`.
