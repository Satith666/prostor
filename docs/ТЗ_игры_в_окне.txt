Добавь в программу модуль «Игры в окне и без рамки». Цель: игра в оконном режиме
или в режиме «без рамки» (Borderless) должна идти так же плавно, как в полноэкранном.

Пример проблемной системы, на которой всё должно работать: Windows 10 22H2, видеокарта NVIDIA RTX 3050,
основной монитор 2560×1440 165 Гц (DisplayPort), второй монитор 1920×1080 60 Гц (HDMI),
масштаб 100% и 150%, запущен Wallpaper Engine. Программа должна работать и на Windows 11,
и с видеокартами AMD и Intel.

ЧТО ПРОВЕРЯТЬ И ИСПРАВЛЯТЬ
Каждый пункт — отдельная строка в списке: статус (в порядке / можно улучшить / недоступно на этой
системе), объяснение простыми словами, кнопка «Исправить» и кнопка «Вернуть как было».

1. Оптимизации для игр в окне (только Windows 11, сборка 22557 и новее).
   HKCU\Software\Microsoft\DirectX\UserGpuPreferences, строковый параметр DirectXUserGlobalSettings,
   ключ SwapEffectUpgradeEnable=1. Остальные ключи в этой строке сохранять, менять только свой.
   На Windows 10 писать: «Недоступно в Windows 10, это одна из главных причин лагов в окне».

2. Переменная частота обновления для игр (Windows 10 1903+ и Windows 11).
   Там же, ключ VRROptimizeEnable=1. Показывать пункт, только если монитор поддерживает
   FreeSync / G-SYNC / Adaptive-Sync.

3. G-SYNC / FreeSync в оконном режиме.
   NVIDIA: по умолчанию G-SYNC работает только в полном экране. Нужен режим «для оконного и
   полноэкранного режимов». Если это можно включить через NVAPI (профили драйвера) — включай,
   иначе показывай пошаговую инструкцию для Панели управления NVIDIA с картинками или текстом.
   AMD: инструкция для AMD Adrenalin.

4. Оптимизация во весь экран для exe игры.
   Найти в HKCU и HKLM\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers
   флаг DISABLEDXMAXIMIZEDWINDOWEDMODE для exe игры и предложить убрать его
   (отключённая оптимизация ухудшает работу в окне и замедляет Alt+Tab).

5. Видеокарта для игры.
   HKCU\Software\Microsoft\DirectX\UserGpuPreferences, параметр = полный путь к exe,
   значение GpuPreference=2; — игра всегда идёт на мощной видеокарте (важно для ноутбуков).

6. Аппаратное планирование GPU (HAGS).
   HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers, HwSchMode: 2 = вкл, 1 = выкл.
   Нужны права администратора и перезагрузка. Это переключатель, а не обязательная «оптимизация»:
   на одних системах помогает, на других нет. Предупредить, что для DLSS Frame Generation он нужен.

7. Режим игры Windows: HKCU\Software\Microsoft\GameBar, AutoGameModeEnabled = 1.

8. Фоновая запись игр (Xbox Game Bar), которая отнимает производительность:
   HKCU\System\GameConfigStore, GameDVR_Enabled = 0;
   HKCU\Software\Microsoft\Windows\CurrentVersion\GameDVR, AppCaptureEnabled = 0.

9. Программы, которые грузят видеокарту, пока игра в окне.
   Найти запущенные Wallpaper Engine, Lively Wallpaper, видео в браузере, оверлеи
   (Discord, GeForce Experience / NVIDIA App, Xbox Game Bar, RTSS) и показать, что с ними делать.
   Для Wallpaper Engine: инструкция «Настройки → Производительность → для других приложений
   в развёрнутом и полноэкранном виде — Пауза». Никакие процессы не закрывать без вопроса.

10. Мониторы с разной частотой обновления.
    Если частота у мониторов разная (например, 165 и 60 Гц), предупредить: в Windows 10 игра в окне
    из-за этого дёргается, особенно если на втором мониторе что-то движется. Предложить поставить
    второму монитору максимальную частоту, которую он поддерживает, и ничего не воспроизводить на нём во время игры.
    Добавить кнопку «Проверить без второго монитора» (Win+P → только основной экран) с возвратом.

11. Ограничение FPS.
    Если включена адаптивная синхронизация, посоветовать ограничить FPS на 3 кадра ниже частоты
    монитора (например, 162 для 165 Гц) через Панель управления NVIDIA («Макс. частота кадров») —
    в окне это сильно выравнивает плавность.

12. Схема электропитания: проверить, что не стоит «Экономия энергии», предложить
    «Высокая производительность» через powercfg с возвратом прежней схемы.

13. (Только по кнопке, по умолчанию выключено) Отключение MPO при мерцании и рывках
    на нескольких мониторах с NVIDIA: HKLM\SOFTWARE\Microsoft\Windows\Dwm, OverlayTestMode = 5
    (DWORD). Нужна перезагрузка. Обязательно кнопка «Вернуть», которая удаляет параметр.

ТРЕБОВАНИЯ К БЕЗОПАСНОСТИ
- Перед любым изменением сохранять старое значение (или отметку «параметра не было»)
  в файл резервной копии. Кнопка «Вернуть всё как было» для всего модуля.
- Ничего не менять без подтверждения. Показывать, что именно меняется и зачем.
- Права администратора запрашивать только для пунктов, которым они нужны (HKLM, powercfg).
- Определять версию Windows, сборку и производителя видеокарты; пункты, которые не подходят,
  не скрывать, а помечать «недоступно» с причиной.
- Писать, где нужна перезагрузка.
- После применения показать итог: что сделано, что не получилось и почему.

ЧЕГО НЕ ДЕЛАТЬ
Никаких сомнительных «твиков» без доказанного эффекта: не отключать Защитник Windows,
службы Windows, HPET через bcdedit, не трогать Win32PrioritySeparation, сетевые твики
и не чистить реестр. Не ставить игре приоритет «Реального времени».
