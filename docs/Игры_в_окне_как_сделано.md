# Модуль «Игры в окне и без рамки» — как выполнено ТЗ

Код: `src/WinPulse.Optimizer/WindowedGames/`, страница: `src/WinPulse.App/Views/FixModuleView.xaml` (общая с «Оптимизацией Windows»).

| № | Пункт ТЗ | Что делает WinPulse | Права | Перезагрузка |
|---|---|---|---|---|
| 1 | SwapEffectUpgradeEnable | `HKCU\Software\Microsoft\DirectX\UserGpuPreferences` → `DirectXUserGlobalSettings`, меняется только ключ `SwapEffectUpgradeEnable=1`, остальные пары сохраняются. На сборке < 22557 — «недоступно» с причиной | нет | нет (перезапуск игры) |
| 2 | VRROptimizeEnable | Та же строка, ключ `VRROptimizeEnable=1`. Сборка ≥ 18362. Без VRR-монитора — «недоступно» | нет | нет (перезапуск игры) |
| 3 | G-SYNC / FreeSync в окне | NVAPI не используется (без подтверждённых идентификаторов настроек не рискуем профилями драйвера). Пошаговая инструкция для NVIDIA / AMD / Intel, кнопка «Открыть панель драйвера», отметка «Я включил» | — | — |
| 4 | DISABLEDXMAXIMIZEDWINDOWEDMODE | Убирается только этот флаг из `AppCompatFlags\Layers` для exe игры в HKCU и HKLM; если других флагов нет — значение удаляется | только для HKLM | нет |
| 5 | GpuPreference=2 | `UserGpuPreferences` → значение с путём exe, ключ `GpuPreference=2`. При одной видеокарте — «недоступно» | нет | нет (перезапуск игры) |
| 6 | HAGS | `HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\HwSchMode` = 2 (вкл) / 1 (выкл, отдельная кнопка с предупреждением). Поддержка и текущее состояние читаются у драйвера (D3DKMT WDDM 2.7 caps). Предупреждение про DLSS Frame Generation | да | да |
| 7 | AutoGameModeEnabled | `HKCU\Software\Microsoft\GameBar\AutoGameModeEnabled=1` (отсутствие параметра = включено по умолчанию) | нет | нет |
| 8 | GameDVR | `HKCU\System\GameConfigStore\GameDVR_Enabled=0` и `HKCU\...\GameDVR\AppCaptureEnabled=0` | нет | нет |
| 9 | Программы, грузящие GPU | Wallpaper Engine, Lively, браузеры (если грузят видеокарту), Discord, оверлей NVIDIA, Game Bar, RTSS — с загрузкой GPU и советом по настройке. «Закрыть» — только после подтверждения, сначала обычный запрос на закрытие, принудительно — только после второго подтверждения. «Запустить снова» | нет | нет |
| 10 | Разные частоты мониторов | Список мониторов: разрешение, частота, максимум, масштаб, VRR. «Поднять частоту» — второму монитору ставится максимальная частота при текущем разрешении (ChangeDisplaySettingsEx, с проверкой CDS_TEST). «Проверить без второго монитора» — монитор временно отключается, окно «Оставить так?» с отсчётом 15 с, без ответа всё возвращается само | нет | нет |
| 11 | FPS на 3 ниже частоты | Считается предел (частота − 3) для монитора с VRR, инструкция для NVIDIA / AMD / Intel / игры / RTSS, отметка «Я настроил» | — | — |
| 12 | Схема питания | «Экономия энергии» → «можно улучшить». Кнопка включает «Высокую производительность» через `powercfg /setactive`; если схема скрыта — создаётся копия (`/duplicatescheme`), при откате копия удаляется, а прежняя схема возвращается | да (по ТЗ) | нет |
| 13 | MPO | Только по кнопке: `HKLM\SOFTWARE\Microsoft\Windows\Dwm\OverlayTestMode=5`. «Вернуть как было» удаляет параметр (если его не было) | да | да |

## Требования безопасности

- **Резервная копия до изменения.** `%LOCALAPPDATA%\WinPulse\backups\windowed-games.json`. Исходное значение (или отметка
  «параметра не было») записывается при первом изменении цели и не перезаписывается повторными «Исправить».
  Для строк вида `A=1;B=2;` копия хранится по каждому ключу отдельно — откат пункта 1 не затрагивает пункт 2.
- **Ничего без подтверждения.** Перед любым изменением — окно со списком: что меняется, было → станет, зачем,
  где (в режиме «Профи» — путь в реестре), нужны ли права и перезагрузка.
- **Права администратора — только для HKLM и powercfg.** Такие изменения собираются в одну пачку и выполняются
  отдельным процессом `WinPulse.exe --elevated-ops` (один запрос UAC). Он выполняет только изменения из белого списка.
- **Неподходящие пункты не скрываются** — помечаются «недоступно на этой системе» с причиной (сборка Windows,
  производитель видеокарты, нет VRR, одна видеокарта, один монитор, не выбрана игра).
- **Перезагрузка** — отмечена на карточке, в окне подтверждения и в итоге (с кнопкой «Перезагрузить сейчас»).
- **Итог** — по каждому изменению: получилось или нет и почему.
- **«Вернуть всё как было»** — откатывает всё из резервной копии модуля, включая отключённый монитор.

## Чего модуль не делает

Не отключает Защитник и службы Windows, не трогает HPET (bcdedit), Win32PrioritySeparation, сетевые параметры,
не чистит реестр и не ставит играм приоритет «Реального времени».
