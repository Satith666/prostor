# План прокачки WinPulse: реальный FPS вместо «твиков»

Принцип: в программу попадает только то, у чего есть измеримый эффект. Каждое изменение — с резервной копией,
откатом и замером FPS «до и после». Запреты из ТЗ остаются (службы, HPET, Win32PrioritySeparation, сетевые твики,
чистка реестра, «реальное время»).

## Проекты с GitHub, на которые опираемся

| Проект | Лицензия | Что берём |
|---|---|---|
| GameTechDev/PresentMon (Intel) | MIT | Замер FPS, 1%/0,1% low, время кадра, GPU Busy — понять, во что упирается игра |
| CXWorld/CapFrameX | MIT | Образец анализа: графики времени кадра, сравнение замеров, перцентили |
| LibreHardwareMonitor | MPL-2.0 | Температуры, частоты, мощность, троттлинг. Датчики процессора — через драйвер PawnIO (WinRing0 блокирует Defender), только с согласия |
| Orbmu2k/nvidiaProfileInspector | MIT | Какие настройки драйвера NVIDIA реально влияют на игру |
| falahati/NvAPIWrapper | LGPL-3.0 | Доступ к профилям драйвера NVIDIA (DRS) из C# |
| beeradmoore/dlss-swapper | GPL-3.0 | Обновление DLSS/FSR/XeSS в играх до свежих версий (качество → можно ставить более быстрый режим) |
| optiscaler/OptiScaler | GPL-3.0 | FSR/XeSS вместо DLSS и генерация кадров FSR 3 на RTX 2000/3000 (у RTX 3050 своей нет) |
| SpecialKO/SpecialK | open source | Точный ограничитель кадров и Latent Sync — ровнее время кадра |
| doitsujin/dxvk | zlib | Старые DX9–DX11 игры с плохой оптимизацией: перевод на Vulkan, иногда сильный прирост |
| valleyofdoom/PC-Tuning, xtw | — | Справочник «что доказано, а что плацебо»; задержки DPC/ISR через ETW |

GPL-инструменты не встраиваются в код WinPulse: программа по кнопке скачивает их официальный релиз с GitHub,
ставит в папку игры с резервной копией оригинальных файлов и проверяет результат замером. В онлайн-играх
с античитом (EAC, BattlEye, Vanguard — определяем по файлам игры) такие моды блокируются.

Осталось: тексты базы знаний (проблемы, BSOD, процессы, автозагрузка — ~900 строк), установщик, автообновление (нужны Releases в репозитории), подпись |

Проверка без Windows: CI собирает, гоняет тесты и делает снимки всех страниц в демо-режиме (ветка `winpulse-shots`).

## Этапы

1. **Дизайн «Кокпит»** — тема, боковое меню с группами, круговые датчики, графики с подсветкой, новый «Пульт».
2. **FPS-лаборатория** — встроенный PresentMon: замер в любой игре, 1% low, график времени кадра, вердикт
   «упираетесь в процессор / в видеокарту / в ограничитель», история и сравнение «до/после».
   **Отчёт об игровой сессии** (по просьбе пользователя): пока идёт игра, каждую секунду пишется нагрузка
   системы и сторонних программ (и FPS, если идёт замер); после игры — разбор, кто мешал и когда.
3. **Где теряются FPS (проверка железа)** — память без XMP/EXPO, одна планка вместо двух, видеокарта не в x16
   или PCIe ниже положенного, монитор подключён к материнской плате вместо видеокарты, игра на встроенной
   графике ноутбука, игра на HDD, перегрев и троттлинг под нагрузкой.
4. **Датчики** — LibreHardwareMonitor: температуры, частоты, мощность; запись вместе с замером FPS.
5. **Игровой режим** — при запуске игры: схема питания, пауза Wallpaper Engine и тяжёлого фона, высокий приоритет
   игре; после выхода всё возвращается.
6. **Драйвер NVIDIA по играм** — низкая задержка, питание «максимальная производительность», ограничение кадров
   драйвером, размер кэша шейдеров; резервная копия профиля.
7. **Апскейлинг и генерация кадров** — обновление DLSS/FSR/XeSS (как DLSS Swapper), OptiScaler для генерации кадров,
   Special K и DXVK для отдельных игр. Только одиночные игры, всё с замером.
8. **Для профи** — задержки DPC/ISR (ETW), статус MSI-прерываний (только показ), подробные журналы.
9. **Релиз** — установщик, подпись, автообновление, английский язык на всех страницах.

## Чего не будет (нет доказанного эффекта или есть риск)

Отключение служб и Защитника, HPET через bcdedit, Win32PrioritySeparation, сетевые твики (Nagle и т. п.),
чистка реестра, «очистка памяти» по таймеру, приоритет «реального времени», готовые «оптимизированные» сборки Windows.
