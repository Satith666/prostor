# Prostor — очистка и анализ диска для Windows 10/11

Исходный код программы и установщика.

## Состав
- `cmd/prostor` — сама программа (Go). Интерфейс — `cmd/prostor/ui` (HTML/CSS/JS, свои значки в `icons.js`). Показывается в собственном окне на WebView2 (`internal/webview2`), а если WebView2 недоступен — в окне Edge в режиме приложения.
- `cmd/prostor/rules/builtin.json` — собственные правила очистки; `cmd/prostor/rules/winapp2.json` — правила из базы [Winapp2](https://github.com/MoscaDotTo/Winapp2) (CC BY-SA 4.0, см. `third_party/winapp2`).
- `internal/rules` — формат правил, конвертер Winapp2 и фильтр безопасности; `cmd/rulegen` — обновление правил: `go run ./cmd/rulegen -in Winapp2.ini`.
- `cmd/prostor/quarantine.go`, `journal.go` — карантин для удалённого вручную и журнал каждого удалённого файла.
- `cmd/prostor/helper.go` — помощник с правами администратора: окно работает без прав, системные действия выполняет копия программы, запущенная через UAC.
- `cmd/prostor/bait.go` — тест приманок (`Prostor.exe --bait-test`).
- `cmd/prostor/selftest.go` — самопроверка (`Prostor.exe --selftest`).
- `cmd/prostor/core_test.go` — модульные тесты (`go test ./...`).
- `cmd/setup` — установщик (нативное окно Win32): копирует программу в Program Files, создаёт ярлыки «Prostor» и «Проверка Prostor», регистрирует удаление в «Приложениях».
- `internal/winapi` — обёртки над Windows API, включая быстрое чтение папок для анализа диска.
- `internal/webui` — локальный сервер и окно; `internal/cdp` — управление браузером для самопроверки интерфейса.
- `tools/mkicon.py` — значок программы, `tools/mkres.py` — значок, манифест и сведения о версии для .exe, `tools/checkpe.py` — проверка ресурсов готового .exe, `tools/mksandbox.py` — тестовый «диск C:» для проверки на Linux.

## Сборка
Нужны Go 1.24+ и Python 3 с Pillow (Windows, Linux или macOS):

```
VER=1.3.0 ./build.sh
```

Результат — `build/Prostor.exe` (можно запускать без установки) и `build/Prostor-Setup-1.3.0.exe`.

## Как устроена безопасность удаления
- Кэш и временные файлы удаляются сразу; каждый удалённый файл записывается в журнал (раздел «История» → «Файлы»).
- Файлы, удалённые вручную в анализе диска и дубликатах, попадают в карантин (по умолчанию на 7 дней) и возвращаются на место одной кнопкой.
- У каждого пункта очистки есть уровень риска; необратимые действия (Windows.old, файлы обновления) по умолчанию не отмечены, а в простом режиме не показываются.
- Из базы Winapp2 берутся только папки кэша, журналов, временных файлов и дампов внутри папки программы. Отбрасываются куки, история, сессии, пароли, настройки, личные папки, кэши установщиков, карантины антивирусов и весь реестр. Правило применяется, только если программа установлена.
- Если файл держит запущенная программа, Prostor называет её (Restart Manager) и предлагает закрыть её и повторить или удалить файл при перезагрузке.
- Тест приманок раскладывает документы, пароли браузеров, ключи мессенджеров, сохранения игр и системные файлы вокруг каждого из 1700+ правил (включая правила Winapp2 и их исключения), запускает очистку по всем правилам и проверяет, что ничего из этого не пострадало, а мусор удалён.

## Проверка программы на ошибки

**На компьютере с Windows** — любой из способов:
- «Пуск → Проверка Prostor» (лучше «Запуск от имени администратора»: тогда проверяются и защищённые системные папки);
- файл `Проверка Prostor.cmd` в папке программы;
- кнопка «Запустить проверку» в разделе «Настройки»;
- из командной строки: `Prostor.exe --selftest` (ключи: `--quick` — без полного анализа системного диска, `--no-open` — не открывать отчёт).

Проверка ничего не удаляет, кроме собственных тестовых файлов. Она проверяет:
- безопасность очистки на тестовых файлах (свежие файлы, исключения, ссылки на другие папки);
- поиск мусора по всем пунктам;
- точность анализа диска (сумма по папкам, жёсткие ссылки, служебное место) и полный анализ системного диска;
- поиск дубликатов, списки программ, автозагрузки и процессов;
- все страницы интерфейса в настоящем браузере: время отрисовки, карту диска, тёмную тему, узкое окно, скорость при замедленном процессоре, ошибки JavaScript.

Отчёт с результатами и снимками экрана сохраняется в `%LOCALAPPDATA%\Prostor\selftest\report-<дата>.html` (хранятся последние 5). Код завершения: 0 — ошибок нет, 1 — есть ошибки.

**Для разработчика (Linux или macOS)** — `./check.sh`: форматирование, `go vet` под Linux и Windows, модульные тесты (включая тест приманок и подмену правил на опасные), синтаксис JS, самопроверка с интерфейсом в Chrome/Chromium на тестовом «диске C:», проверка помощника с правами, сборка установщика и проверка ресурсов .exe. Нужны Go, Python 3 с Pillow, Node.js и Chrome/Chromium (путь можно задать в `PROSTOR_BROWSER`).

**Автотесты на настоящей Windows** — `.github/workflows/ci.yml` и `ci/windows.ps1`: на каждый push GitHub Actions собирает установщик на Linux, затем на Windows Server 2025, Windows Server 2022 и Windows 11 ARM ставит его без вопросов, проверяет окно WebView2, тест приманок в песочнице и на живой системе, помощника с правами, полную самопроверку и удаление. Отчёты лежат в артефактах запуска. Выпуск на странице Releases: «Actions → CI → Run workflow» с номером версии (или тег `v*`) — установщик публикуется, только если все проверки на Windows пройдены.

## Полезное
- Журнал работы: `%LOCALAPPDATA%\Prostor\prostor.log`
- Настройки и история: `%LOCALAPPDATA%\Prostor\settings.json`, `history.json`
- Тихая установка: `Prostor-Setup-1.3.0.exe /S` (папку можно задать `/D=C:\Путь`)
- Удаление: «Параметры → Приложения» или `Prostor.exe --uninstall`
