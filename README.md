# WinPulse

Программа для диагностики нагрузки и оптимизации Windows: показывает, что именно тормозит,
безопасно исправляет найденное (с откатом любого изменения), помогает играм и проверяет драйверы.

Подробный план: https://claude.ai/artifact/FZdnLWwbRcrLaPv1ramyhy
Макеты интерфейса (выбран вариант B «Пульт»): https://claude.ai/artifact/7PJAeY44RpR6gXBhqqK7W4

Программа собирается: GitHub Actions на каждый push собирает `WinPulse.exe` (вкладка Actions → последний запуск → Artifacts → WinPulse-win-x64) и гоняет тесты.
На живой системе программа ещё не проверялась: если она падает, пришлите `%LOCALAPPDATA%\WinPulse\logs\winpulse.log`.

## Как собрать

1. Нужен .NET 10 SDK. Если его нет, `build.cmd` предложит скачать его сам в папку `.dotnet` (без прав администратора). Вручную: https://dotnet.microsoft.com/download/dotnet/10.0 (колонка SDK, Windows x64 Installer).
2. Распакуйте архив (не запускайте файлы прямо из ZIP).
3. Дважды щёлкните `build.cmd`. Окно не закроется само: в конце будет «Нажмите любую клавишу».
4. Готовый файл: `dist\WinPulse.exe` (один файл, .NET для запуска ставить не нужно).
5. `dist\WinPulse.exe --demo` — запуск на выдуманных данных (удобно посмотреть интерфейс и проверить выводы).

Если сборка упала — `build.cmd` сам откроет папку с файлом `build-errors.txt`; его и нужно прислать.
Если не прошли тесты — пришлите `test-log.txt`.

`build.cmd` хранится в кодировке CP866 с переводами строк CRLF (см. `.gitattributes`): так cmd.exe
правильно читает русский текст. Редактируйте его редактором, который сохраняет кодировку.

## Где программа хранит данные

`%LOCALAPPDATA%\WinPulse\`:
- `settings.json` — язык, режим «Профи», выбранная игра, отметки «я сделал»;
- `backups\windowed-games.json`, `optimization.json`, `startup.json` — исходные значения всего, что менял WinPulse (для «Вернуть как было»);
- `logs\winpulse.log` — журнал, включая каждое применённое изменение.

Права администратора программа просит только для изменений HKLM и powercfg — отдельным процессом
`WinPulse.exe --elevated-ops`, который выполняет лишь изменения из белого списка.

Через Visual Studio 2022/2026: откройте `WinPulse.sln`, стартовый проект — `WinPulse.App`.

## Структура

```
src/WinPulse.Core        логика без привязки к Windows: модели, группировка процессов, история, выводы,
                         разбор EDID, детекторы проблем и база кодов синих экранов, демо-данные
src/WinPulse.Collectors  сбор данных Windows: процессы (NtQuerySystemInformation), PDH, DXGI, диски, сеть,
                         мониторы и EDID, HAGS, журналы событий (wevtapi), устройства (cfgmgr32), здоровье дисков
src/WinPulse.Optimizer   изменения системы: резервная копия, применение, откат, повышение прав,
                         модули «Игры в окне» (13 пунктов) и «Оптимизация» (8), автозагрузка, Планировщик
src/WinPulse.App         интерфейс WPF «Пульт»
tests/WinPulse.Core.Tests  юнит-тесты (ядро, детекторы, разбор журналов)
docs/                    ТЗ модулей
.github/workflows        сборка и тесты на Windows в GitHub Actions
```

Будут добавлены: `WinPulse.Service` (служба), `WinPulse.Cli`.
