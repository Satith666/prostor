“Disable fullscreen optimizations” checkbox
This checkbox in the exe properties (Compatibility tab) stops Windows from using modern presentation for the game. In borderless mode it adds latency and can break VRR. The flag should be removed.
Pick a game at the top of the page first — this item is set per game executable.
5
Run the game on the high-performance GPU
Tells Windows to run the game on the powerful GPU (“High performance” in Graphics settings). Matters for laptops and PCs with integrated graphics.
6
Hardware-accelerated GPU scheduling (HAGS)
The GPU manages its own work queue instead of Windows. Required for DLSS Frame Generation; barely affects regular FPS (0–2%), sometimes slightly lowers latency. Needs admin rights and a restart.
Don't turn HAGS off if you use DLSS Frame Generation — it doesn't work without it.

10
Monitors with different refresh rates
With monitors like 165 Hz and 60 Hz side by side, a windowed game on Windows 10 can sync to the slower one and stutter. Raising the second monitor to its maximum refresh rate helps; to test, temporarily turn it off. Windows 11 is less affected.
Only one monitor is connected — nothing to do.
11
Cap FPS 3 below the refresh rate
With G-SYNC/FreeSync, frames must stay inside the VRR range. When FPS hits the refresh rate, regular V-Sync kicks in or tearing appears, and latency grows. A cap slightly below the refresh rate keeps the game inside the range.
Without G-SYNC/FreeSync this cap isn't needed — your monitors don't report VRR support.
12
Power plan
High performance
The Power saver plan lowers CPU and GPU clocks, so games lose frames. High performance is better for gaming. The previous plan is saved and restored with one click.
13
Disable MPO (flicker and black flashes)
Multi-Plane Overlay makes presenting frames cheaper, but on some systems (often NVIDIA with several monitors) it causes flicker, black flashes and stutter in windowed mode. Only disable it if you see these problems. Requires a restart. On recent Windows 11 builds the setting may have no effect.
Only change this if you see flicker or black flashes.
